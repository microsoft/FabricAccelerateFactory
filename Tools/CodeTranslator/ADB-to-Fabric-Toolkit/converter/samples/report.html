Only notebooks with status Converted count as complete; review and manual-work notebooks do not. Skipped files are excluded. Weighted construct coverage: 25.7% = (2 auto + 0.5 x 14 review) / 35 Databricks-specific constructs (strict, auto only: 5.7%). Constructs are pooled across notebooks, not averaged per notebook. Platform-neutral Spark code and mechanical cell-magic conversions (%md, %sql, %python, %pip) are not scored. A notebook with no scored constructs has 100% construct coverage but contributes no constructs to the pooled score. The code-line metric only measures lines without manual flags; review lines are included. These are static-analysis metrics, not runtime validation.
