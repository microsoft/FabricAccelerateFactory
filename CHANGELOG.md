# 1.0.0
(2025-10-22)

*Features*

Initial open source release of Fabric Migration Factory - this version includes:

**Tools**
* Azure Databricks to Synapse or Fabric notebook converter with PowerShell automation
* Semantic model translation utilities for Power BI migrations (import model to direct lake)
* Data reconciliation tool for Azure SQL vs Fabric SQL validation
* Performance testing suite comparing Fabric SQL vs Azure SQL
* Power BI visuals performance testing tools

**Templates**
* Migration patterns and standardized templates
* Comprehensive documentation and getting started guides
